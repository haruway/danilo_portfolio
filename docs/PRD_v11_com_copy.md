## 1. Posicionamento

### Tese
Uma marca precisa existir em fachada, embalagem, uniforme, impresso, feed e vídeo. Normalmente isso passa por quatro fornecedores — fotógrafo, designer, finalizador, editor. **Aqui passa por um.**

### O que NÃO usar
- ❌ Título "Creative AI Director" — inflação de senioridade, some do site
- ❌ "Construo marcas do zero" — falso, contradiz o trabalho real
- ❌ "Não basta ser, precisa parecer ser" — bordão da Dzigna, não é dele
- ❌ Motion Design / After Effects — ele não domina, não vender
- ❌ Nome de ferramenta de IA como credencial (envelhece em 6 meses)

### Público
1. **Cliente freela direto** (prioridade) — dono de negócio, não designer
2. Agência / estúdio
3. Empresa (CLT/remoto)

**Consequência de design:** forma sofisticada, conteúdo brutalmente claro. Três caminhos que precisam ser óbvios em 5 segundos: *o que ele faz*, *o que já fez*, *como falo com ele*. Todo o resto pode ser cinematográfico.

## 4. Direção visual

### Princípio único
**Ousadia no que se vê, clareza no que se usa.**

Radical em: tipografia, escala, cor, transição, textura, ritmo de scroll, composição.
Nunca radical em: navegação, leitura do que ele faz, caminho até o contato.

### Tokens (herda do v10, funciona)
```css
--dark:   #080706
--gold:   #FFBE57
--cream:  #EDE5D4
--white:  #FFFFFF
```

### Tipografia
- **Relaxe** — display: nome, títulos de seção. Uso com restrição.
- **Smart Sans** — utilitário: nav, eyebrows, labels, dividers.
- **DM Sans** — corpo.

⚠️ Verificar publicação dos arquivos `.ttf`/`.otf` no Netlify **antes de qualquer build**. Se não carregam, o site inteiro cai para sans-serif genérica — hipótese principal para o "ficou em branco".

### Elemento assinatura
As **letras magnéticas do hero**. É a única extravagância que fica no caminho do usuário, e por isso é a única que se justifica ali. Todo o resto da ousadia acontece depois do primeiro scroll.

### Correções técnicas obrigatórias
| Item | Ação |
|---|---|
| Scroll hijack + ScrollTrigger + sticky | Escolher um. Recomendado: Lenis + ScrollTrigger |
| Grain 200vw animado infinito | PNG estático ou animação só em `transform` |
| Letras magnéticas | Cachear `getBoundingClientRect` no resize |
| `cursor: none` | Fallback se JS falhar |
| Meta tags | `description` + `og:image` + favicon — hoje o link é retângulo cinza |
| Breakpoints | 480 / 768 / 1024 / 1440 (hoje existe **um** só) |
| Contraste | Nada abaixo de 12px. Fim dos `rgba(...,.45)` em 9px |
| Emojis no Stack | Remover. Logo monocromático ou texto |
| Cards "Em Breve" | Remover os dois |
| Thumbs do YouTube | Hospedar localmente |
